# What data files you need and where to find them

*File 1:* `RGD1CHNO_AMsmiles.csv`
- Atom-mapped SMILES for reactants and products of all RGD1 reactions
- Also contains `MR_#####_#` style labels for all RGD1 reactions, as well as barriers and heats of reaction
- Download from (RDG1 figshare repo)[https://figshare.com/articles/dataset/model_reaction_database/21066901]

*File 2:* `Freaction_features.csv`
- Reports `N_bond_break` and `N_bond_form` for all RGD1 reactions
- Also contains `MR_#####_#` style labels for all RGD1 reactions, as well as other reaction statistics
- Download from Qiyuan Zhao's (RGD1 GitHub repo)[https://github.com/zhaoqy1996/RGD1]
